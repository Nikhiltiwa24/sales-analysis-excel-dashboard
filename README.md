# 📊 Sales Analysis Dashboard – Excel

An interactive Sales Analysis Dashboard developed using Microsoft Excel and Power Pivot to analyze sales performance, customer spending, product performance, occasions, monthly trends, order timing, and geographical order distribution.

---

## 📌 Project Overview

This project transforms raw transactional sales data into an interactive business intelligence dashboard.

The dashboard provides a consolidated view of key sales and operational KPIs and allows users to analyze performance using interactive slicers and PivotCharts.

---

## 🎯 Business Objective

The primary objective of this project is to:

- Analyze overall sales performance
- Track total revenue and total orders
- Analyze customer spending
- Identify high-performing product categories
- Identify high-performing products
- Analyze revenue by occasion
- Identify monthly revenue trends
- Analyze order patterns by hour
- Analyze order distribution across cities
- Monitor order-to-delivery time

---

## 🔍 Key Insights

- Total revenue generated was ₹35.21 lakh across 1,000 orders.
- Average customer spending was ₹3,520.98.
- Colors was the highest-revenue category in the dashboard.
- Anniversary generated the highest revenue among the displayed occasions.
- Revenue varied significantly across different months.
- Magnum Set was the highest-revenue product among the displayed Top 5 products.
- The average order-to-delivery time was 5.53 days.
- Order volumes varied across cities.
